# ppWeather
Ricreazione dell'app "_***Lazy Weather***_" nel linguaggio Haxe. Segue il target originale, ***Android***.

### Aggiunte e miglioramenti
- Il motore è programmato in modo che ottenga le informazioni da un'api pubblica.
- Aggiunti sfondi dinamici in base all'orario e alle condizioni meteorologiche.

### Stato attuale
L'app risulta perfettamente funzionante e si può scaricare per ***Android***, mentre gli altri target come ***Windows***, ***MacOS***, ***iOS*** e ***Linux*** non sono stati testati o risultano non funzionanti.
